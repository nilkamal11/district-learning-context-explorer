# Data notice

The MIT license in this repository applies to the code written for this project. It does not apply to source data or documentation produced by Stanford's Educational Opportunity Project or other data providers.

This project does not redistribute the original SEDA source files, the local DuckDB database, or unrestricted working outputs. It publishes selected derived fields needed by the public browser experience. The initial dashboard bundle contains the district catalog, 2024 context, and grade-4 achievement records; five separately checked, lazy-loaded bundles add grade 3 and grades 5 through 8. Together, those field-limited bundles cover the all-student, administrative-district Cohort Standardized analytical records used by the workbench. Users obtain the source release directly from the official Stanford repository and remain responsible for following the provider's terms and citation guidance.

Stanford's Data Use Agreement limits the datasets to permitted noncommercial use, prohibits re-identification, and requires permission for publication. Stanford confirmed to the project owner that this Git portfolio use is permitted. That confirmation does not transfer data rights to repository users or authorize another use.

The analysis is independent. Stanford University, the Educational Opportunity Project, HMH, and NWEA have not endorsed it.
