How to read these numbers

This page uses SEDA’s Cohort Standardized scale. The number measures the distance between a district’s estimated average and SEDA’s fixed national reference for the same grade and subject. Zero matches the reference. Positive numbers are above it and negative numbers are below it. The unit is a standard deviation, which lets Stanford place results from different state tests on one common scale.

A score of +0.89 means the district’s estimated average is about 0.89 standard deviations above the reference. It is not 89% and it is not an individual student score. The smaller range below each score shows uncertainty. For example, if the estimate is +1.03 and the range is +0.89 to +1.16, +1.03 is the best estimate and the other two numbers are the lower and upper ends of the range.

Orange is the selected district. The dotted blue line is the typical result among comparison districts, the shaded area contains the middle 50%, and thin orange bars show uncertainty. Each point is the estimated district average for students tested that year. SEDA has no annual estimates for 2020 or 2021. Worked study design

How I would build data for a new research question

This study plan shows how I would join 2022–2024 SEDA estimates with public finance, enrollment, staffing, and inflation data. No results have been calculated.

2022–2024 Grade 4 math Four public data sources

Study question

Did districts that increased instructional spending per student also improve faster in fourth-grade math?

Years
2022–2024
Unit of analysis
District × year × grade × subject
Data sources
Four public systems
Interpretation
Association, not causation

The required information is stored in separate systems

Achievement, spending, enrollment, staffing, inflation, and district identity are stored in separate files. The joins must account for changing district IDs, source years, units, duplicates, and missing records.

How the public sources would be joined

Each source answers a different part of the question. The crosswalk is the lookup table that keeps district identities aligned as identifiers change.

  1. 01 SEDA achievement

    Stanford Education Data Archive annual achievement estimates, uncertainty, and test counts.

    SEDA 2025.2 ↗
  2. 02 District crosswalk

    A year-specific lookup links SEDA’s stable district ID to the federal ID used in each year’s source files.

  3. 03 Finance and staffing

    Census school-finance records plus federal enrollment and staffing records.

  4. 04 Inflation and timing

    Convert spending to constant dollars per student and align resource years before outcome years.

  5. 05 Analysis file

    One documented row per stable district, year, grade, and subject, plus join-quality flags.

District ID check 174 crosswalk records need an ID change

The released SEDA crosswalk contains 174 administrative-district records where the source district ID differs from the stable SEDA ID. The join therefore uses the district ID listed for each year and produces an unmatched and duplicate-key report.

    How the comparison score is calculated

    comparison score = 0.25 × (size difference + economic difference + composition difference + place difference)

    District size

    Student enrollment in grades 3–8

    Economic context

    Family poverty and local economic conditions

    Student composition

    District race and ethnicity shares

    Place

    City, suburb, town, and rural mix

    I used equal weights because I didn’t have a good reason to favor one factor. Test scores are not part of this calculation. My first sensitivity check would be to see how much the group changes under different weights.

    1. Use 2024 community information, the latest year with the full set of context fields, and hold that snapshot fixed across the chart.
    2. Start with districts in the same state that have a similar grade range, locale, enrollment, and poverty rate.
    3. Select up to 15 same-state districts; at least 10 are required for the main comparison.
    4. If there are too few in-state districts, show a separate nationwide comparison group.
    5. Report whenever the search rules had to be widened.

    Rules for comparison language

    Same-state comparison

    The dashboard uses within-state standard errors. It says “higher” or “lower” only when at least 10 comparison districts report data, coverage reaches 70%, and the selected estimate is precise enough.

    Nationwide comparison

    The dashboard uses cross-state adjusted standard errors and presents the result as context. State-level linking uncertainty can be shared across districts, so no higher-or-lower label is assigned.
